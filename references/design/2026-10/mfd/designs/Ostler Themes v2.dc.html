OSTLER THEMES · V2 · STRUCTURE, NOT JUST COLOUR
Twelve themes that each look like a different instrument
Same screen in every theme: Diagnose and Engine side by side. Each theme’s CSS changes the frame, labels, numbers, gauge style, controls, strip and divider. What never changes: layout, tile sizes, touch targets, the drag handles between tiles, warning and caution colours, and safety icons. Themes style the screen only; steering-wheel and soft-key controls come later as a separate overlay app.
Two designs, not a filterEach theme ships a day and a night version, drawn separately. Night lowers brightness and avoids pure white; day raises contrast for sunlight.
SwitchingSettings → Themes: Auto, Day or Night. Auto follows the headlights signal when the gateway has it, then the light sensor, then sunset at the car’s position.
While movingThe theme’s safe version: opaque surfaces, no blur or glow, plain wallpaper behind driver tiles, warning colours locked.
Theme fileEach theme is one CSS file with a day and a night block. Ostler checks contrast and minimum sizes for both before it can be used.
