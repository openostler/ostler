Big screens: pages side by side, spanning, split screen
Frames L-01 to L-13. Sizes in dp. Night and LHD. Builds on edit mode v3.
dp everywhereSize classes, the 24 dp moving floor and touch targets are in density-independent pixels, so text stays the same physical size on sharp 15″ panels.
Pages are columnsA page is at least 720 dp wide and full height. Wider windows show more pages, like a foldable opening; narrower ones spill pages back into the carousel. Tiles may change size class between screens; a layout’s shape never changes.
SpanningOn a wide window, drag an edge across the page line and the tile spans pages. When the window drops to one page, it shrinks onto its home page.
Two versionsEach layout keeps a Wide and a Single-page version. The single one is made on first need and edited separately; neither rewrites the other.
Big-screen safetyPinned driver column from 12″ up. Warnings go to the driver-side top. Edit controls sit in the driver half.
