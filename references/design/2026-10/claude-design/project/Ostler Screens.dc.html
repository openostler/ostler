OSTLER · CORE SCREENS · NIGHT + ONE DAY
Home, Drive mode, Trips, Trip detail
Reference car: 2002 Discovery 2 Td5, right-hand drive — so the rail sits on the right, map sheets on the left. Maps are live OpenFreeMap vector tiles (dark / positron) with routes snapped to real roads in the Peak District.
Assumptions — Speed ramp hexes weren't in the brief, so I used a six-step violet lightness ramp (faster = lighter at night, darker by day). Swap them in once you have §4.3.
Drive mode — the screen shown while Moving. Coolant's band is “below 105 °C”, so a cold 28 °C stays neutral. The Trip tile has no normal range, so it shows time and average speed instead of a bar.
Tweaks — Faults on/off, Ghost/Visible and live data apply to every screen. Time/Distance and the signal picker work in Trip detail.
